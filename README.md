# 合成大果蛙

一个单文件 HTML5 休闲合成小游戏，玩法参考《合成大西瓜》。

## 在线试玩

https://bking0401.github.io/frog-game/

## 说明

- 纯 HTML + CSS + JavaScript，物理引擎 Matter.js 已内嵌，**不依赖任何外部资源**
- 双击 `index.html` 即可离线游玩，无需联网、无需安装
- 同时支持鼠标与触屏操作

## 玩法

两个同级果蛙相撞会合成更高一级：

烂香蕉 → 葡萄 → 橘子 → 草莓 → 荔枝 → 桃子 → 榴莲 → 西瓜 → 金蕉蛙

- 果蛙顶部越过警戒线并停留 1.4 秒即失败
- 每 2000 分获得一张复活卡，可清除越线果蛙继续游戏
- 两个金蕉蛙相撞直接消除，得 256 分
